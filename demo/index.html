    Reproduce every verdict

    git clone https://github.com/iamhuman-cheolheelee/k-probe.git && cd k-probe
pip install mlx-lm            # Apple silicon; see README for other back-ends
python harness/run.py mlx-community/Apertus-8B-Instruct-2509-4bit
python demo/build.py          # writes demo/index.html with your results

    Greedy decoding, max 320 new tokens, the model's own chat template, no system prompt. The scorer in this page and in the harness is the same rule set, so your verdicts will match ours.
